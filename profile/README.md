# Wishted

Wishted — сервис вишлистов и подарков. Создавай списки желаний, делись с друзьями, бронируй подарки в Telegram Mini App или на сайте.

---

## 🚀 Наш продукт

**Сайт:** [wishted.com](https://wishted.com)

**Telegram-бот:** [@wishtedbot](https://t.me/wishted_bot)

**Mini App:** доступен внутри Telegram-бота [@wishtedbot](https://t.me/wishted_bot)

## Возможности

- Создание вишлистов на любой повод
- Парсер товаров по ссылке (Ozon, Wildberries, Яндекс.Маркет)
- Бронирование подарков друзьями
- Telegram Mini App для быстрого доступа
- Telegram-бот с inline-командами
- Premium-подписка с расширенными лимитами и дополнительными возможностями

## 🛠 Стек

`Next.js 16` · `TypeScript` · `React 19` · `Prisma` · `PostgreSQL` · `Docker`
